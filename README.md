# MSCS532 Assignment 2 – Divide-and-Conquer Algorithms

This repository contains the analysis and Python implementations of two divide-and-conquer algorithms: Merge Sort and Quick Sort. The project includes theoretical time complexity analysis using asymptotic notation and recurrence relations, along with practical performance comparisons on different datasets.

Course: MSCS532 – Algorithms and Data Structures  
Assignment: Assignment 2  
Language: Python  

The written report is included separately and references the implementations in this repository.
